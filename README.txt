Smart Calculator with History (DSA Project)
Students: Rathod Vraj (26MCA050), Hardevsinh Zala (26MCA063)
Faculty : Assistant Professor Nirav Patel

HOW TO RUN
1. gcc backend.c -o backend        (Windows: gcc backend.c -o backend.exe)
2. python server.py
3. Open http://localhost:8000 in the browser

FILES
backend.c  - C backend: queue, stack, infix to postfix, evaluation, doubly linked list history
server.py  - connects the page and backend.c (no logic, only passes messages)
index.html, style.css, script.js - web page (frontend)
26MCA050_Smart_Calculator.pptx - presentation 
26MCA050_Smart_Calculator_Report.docx / .pdf - report
